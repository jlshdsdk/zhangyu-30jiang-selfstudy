# 张宇考研数学基础30讲·高等数学 —— 零基础部分自学站

据《张宇考研数学基础30讲·高等数学分册（2026版）》**零基础部分（书页 P1–P47）**整理的纯静态多页自学网站，用于快速过一遍高中到大学的衔接知识。

## 内容

只含两类内容，忠于原书：

- **核心知识点**：定义、定理、公式、重要结论，速记要点式呈现；
- **书本例题**：完整题目 + 原书逐步解答（例1–例75，编号与原书一致）。

目录结构与原书零基础部分知识树一一对应：基本逻辑 / 解析式的概念与运算 / 方程与不等式 / 函数 / 数列及其单调性 / 坐标系及其变换。其中 **★三角函数与反三角函数** 为重点小节，额外提供公式推导脉络、记忆口诀、易混淆点对比与例题逐行拆解（标注"拆解"的内容为便于记忆所作的整理）。

## 使用

- 入口：`index.html`（直接双击打开即可，也可部署到任意静态服务器）。
- 数学公式由本地 `vendor/katex/` 渲染，**无任何 CDN 外链，完全离线可用**。
- 纯 HTML/CSS/JS，无框架、无构建步骤。

## 技术说明

- 所有页面共享 `style.css` 与 `main.js`，链接均为相对路径。
- KaTeX 0.16.22（css/js/woff2/woff 字体）已全部本地化。

仅供个人自学使用。
