二、解析式的概念与运算

解析式的概念

解析式的概念

解析式的概念结构如下：

解析式
├── 代数式
│   ├── 有理式
│   │   ├── 整式
│   │   │   ├── 单项式
│   │   │   └── 多项式
│   │   └── 分式
│   └── 无理式
└── 超越式

单项式：数与字母的积组成的代数式，其中数叫系数，所有字母的指数和叫次数.

如 $2a$，$3b^2$，$-ab$，$0$，则 $2a$ 中，$2$ 是系数，$2a$ 叫一次单项式；$3b^2$ 中，$3$ 是系数，$3b^2$ 叫二次单项式；$-ab$ 中，$-1$ 是系数，$-ab$ 叫二次单项式；$0$ 中，$0$ 是系数，$0$ 叫零次单项式.

多项式：单项式的和叫多项式，所有单项式中的最高次数，叫多项式的次数.

如 $2a + 3b^2 - ab$，其中 $2a$，$3b^2$，$-ab$ 叫多项式的项，$2a + 3b^2 - ab$ 是二次多项式，再如，$abc^2 + 1$ 是四次多项式.

整式：单项式与多项式统称整式.

分式：设 $A$，$B$ 为整式，$B$ 中有字母，则 $\dfrac{A}{B}$ 叫分式. 若求分式的定义域，要记得考虑 $B \neq 0$. 如 $\dfrac{2x^2 + 1}{3x^3 + 4x - 5}$，$\dfrac{x^4 + 1}{x + 1}$，$\dfrac{xy - z}{x^2 y^2 + z}$ 均为分式.

当 $A$ 的次数小于 $B$ 的次数时，称为真分式；否则称为假分式，如 $\dfrac{2x^2 + 1}{3x^3 + 4x - 5}$，$\dfrac{xy - z}{x^2 y^2 + z}$ 是真分式，$\dfrac{x^4 + 1}{x + 1}$ 是假分式.

有理式：分式和整式统称有理式.

无理式：含有字母的根式运算的代数式. 如 $\sqrt{2x}$ 是无理式，$\sqrt{2}x$ 是有理式.

代数式：有理式和无理式统称代数式，即由数与字母作有限次加、减、乘、除、开方、乘方等代数运算得到的式子.

超越式：含有字母的指数为无理数的指数运算、对数运算、三角运算和反三角运算的解析式，以上运算也称为初等超越运算，以区别于加、减、乘、除、开方、乘方这些初等代数运算，如 $\ln\left(x^2 + y^2\right)$，$\arctan x$，$a^{\sqrt{2}}$ 等均为超越式.

解析式：代数式与超越式统称解析式.

速记

判断"是什么式"只看两问：有没有字母开方？ 有 → 无理式；有没有超越运算（指数含字母、对数、三角、反三角）？ 有 → 超越式；剩下按"整式 / 分式"归类即可.
