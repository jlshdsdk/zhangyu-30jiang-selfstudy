一、基本逻辑

对立判断

$\overline{A}$ 是 $A$ 的对立判断

(1) 若 $A \Rightarrow B$，则 $\overline{B} \Rightarrow \overline{A}$.

(2) $\overline{A \cup B} = \overline{A} \cap \overline{B}$.

(3) $\overline{A \cap B} = \overline{A} \cup \overline{B}$.

速记

(1) 就是"逆否命题与原命题同真假"：正着推不了反着来，否后推否前.

(2)(3) 合称德摩根（De Morgan）法则，口诀：长横线一拆，且变或、或变且（$\cup \leftrightarrow \cap$）.

例3

命题 $p$：若存在 $a \in \mathbf{R}$ 且 $a \neq 0$，对任意的 $x \in \mathbf{R}$，均有 $f(x+a) < f(x) + f(a)$ 恒成立.

已知命题 $q_1$：$f(x)$ 严格单调减少，且 $f(x) > 0$ 恒成立；命题 $q_2$：$f(x)$ 严格单调增加，且存在 $x_0 < 0$，使得 $f(x_0) = 0$. 则下列说法正确的是（　　）.

(A) $q_1$，$q_2$ 都是 $p$ 的充分条件　　(B) 只有 $q_1$ 是 $p$ 的充分条件

(C) 只有 $q_2$ 是 $p$ 的充分条件　　(D) $q_1$，$q_2$ 都不是 $p$ 的充分条件

解 应选 (A).

由命题 $q_1$，$f(x)$ 严格单调减少，且 $f(x) > 0$，故存在 $a > 0$，使得 $f(x+a) < f(x) < f(x) + f(a)$，$q_1$ 是 $p$ 的充分条件；由命题 $q_2$，取 $a = x_0 < 0$，则 $x + a < x$，$f(a) = 0$，由 $f(x)$ 严格单调增加，有 $f(x+a) < f(x) = f(x) + f(a)$，$q_2$ 也是 $p$ 的充分条件.

例4

设数列 $\{a_n\}$ 是等比数列，则 "$a_1 < a_2 < a_3$" 是 $\{a_n\}$ 是严格单调增加数列的（　　）.

(A) 充分非必要条件　　(B) 必要非充分条件

(C) 充分必要条件　　(D) 既非充分也非必要条件

解 应选 (C).

$\{a_n\}$ 严格单调增加，故 $a_1 < a_2 < a_3$，必要性成立.

又当 $a_1 < a_2 < a_3$ 时，因 $a_n = a_1 q^{n-1}$，$n = 1, 2, \cdots$，有 $a_1 < a_1 q < a_1 q^2$.

①当 $a_1 > 0$ 时，$q > 1$，$a_n = a_1 q^{n-1}$ 是严格单调增加数列；

②当 $a_1 < 0$ 时，$0 < q < 1$，$a_n = a_1 q^{n-1}$ 是严格单调增加数列. 充分性成立.

提醒

等比数列讨论单调性时，$a_1$ 的正负决定公比 $q$ 的范围，两种情形都要讨论——这是本题充分性的关键一步.
